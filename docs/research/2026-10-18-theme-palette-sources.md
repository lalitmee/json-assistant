# Unified theme palette sources

Color values below are taken from the named upstream theme files, not adjusted for JSON Assistant. Semantic labels map existing UI/editor roles to the nearest original palette colors.

| Tokyo Night   | [tokyo-night-vscode-theme](https://github.com/tokyo-night/tokyo-night-vscode-theme/blob/master/themes/tokyo-night-color-theme.json), Tokyo Night; [light file](https://github.com/tokyo-night/tokyo-night-vscode-theme/blob/master/themes/tokyo-night-light-color-theme.json), Tokyo Night Light | dark background `#1a1b26`, foreground `#a9b1d6`, accent `#7aa2f7`; light background `#e6e7ed`, foreground `#343b59`, accent `#2959aa`                                                                             |
| Catppuccin    | [catppuccin/palette](https://github.com/catppuccin/palette/blob/main/palette.json), Mocha and Latte                                                                                                                                                                                              | Mocha base/text/blue `#1e1e2e` / `#cdd6f4` / `#89b4fa`; Latte base/text/blue `#eff1f5` / `#4c4f69` / `#1e66f5`                                                                                                    |
