# JSON Assistant 0.1.0

An early colleague-testing release of the browser-based JSON Assistant.

## Included

- Inspect JSON in source and tree views, search fields, edit values, and format or minify documents.
- Undo and redo edits; copy JSON, paths, or subtrees; open and download files.
- Adjust workspace appearance and editor themes.
- Document processing stays in the browser; JSON payloads are not uploaded to the hosting service.

## Known limitations

- The 1 MiB broad-array workflow is not supported: the default guardrail refuses it. A higher experimental limit caused editor failures, so it is intentionally not enabled.
- 100 MB benchmark cases crashed or timed out. Payload capacity and responsiveness depend on browser and device; no unlimited-size support is promised.
- Document contents are not automatically saved or recovered. Avoid using this testing release as the only copy of important data.

Please report workflow failures and browser/device details so the next release can address them.
