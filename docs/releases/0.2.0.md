# JSON Assistant 0.2.0

An early colleague-testing release of the browser-based JSON Assistant.

## Included

- Inspect and edit one JSON document in Code, Tree, or Split views; search fields and source.
- Open or paste documents, format or minify, undo or redo, copy paths or subtrees, and download source.
- Choose packaged editor fonts, previews, color themes, and light or dark appearance.
- See processing feedback while documents are analyzed.
- JSON processing remains in the browser; the app does not upload document contents to a backend.

## Known limitations

- The 1 MiB broad-array workflow is unsupported: the default guardrail refuses it.
- 100 MB benchmark cases crashed or timed out. Capacity and responsiveness depend on the browser, device, and document shape; no unlimited-size support is promised.
- Document contents are not automatically saved or recovered. Export important work and keep another copy.
